## 交付约束

- 保留项目格式 v1、九工具契约、Node >=24.22.1 <27 与 Windows x64 声明。

- 锁争用立即返回可重试错误；遗留锁须关闭所有相关宿主后人工清理。

每项记录旧基线复现、修复验证、同族回归、重复与重启行为、命令及独立退出码。性能使用固定 50/200/1000 页夹具和同机对照，不以单次耗时作为通过条件。正式 Windows 浏览器测试必须零失败、零取消、零跳过。
