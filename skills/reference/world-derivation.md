# 世界推导：如何避免「所有 AI 页面长得一样」

判据来源：impeccable（Apache-2.0，Paul Bakaus）`skill/reference/new-work-world.md` 步骤 1–2、`mode-operate.md`、`mode-read.md`、`bolder.md` 的 skeleton test。中文文案与流程表述为本项目重写。

这份文档是 `skills/SKILL.md` 双首屏流程的前置步骤：**先把视觉世界推导出来，再出首屏**。只在 persuade 页面走双首屏；operate / read / experience 页面按下面的模式约束直接深化一个方向。

## 步骤 1 · 先点名窠臼

在动笔前用四句话固定前提：

1. 这个产品**唯一**的机制是什么（一句话）；
2. 受众的**真实场景**是什么；
3. 这个受众的**文化家园**在哪（不是"科技圈"，而是具体的行业、地域、代际经验）；
4. 这个首屏**必须证明**什么。

然后写下「**这个类别永远会发的那张页面**」——以及它**可预测的反面**。两者都是窠臼，**都从候选里剔除**。

- 简报里自带的画面（客户说"要一个像某某那样的页面"）、产品名本身、简报里被命名的器物、统摄性的隐喻，都算**字面读法**：最多只占 1 个候选，其余候选必须来自受众世界的别处。

## 步骤 2 · 列出 7 个具体视觉系统

从受众的文化世界里列出 **7 个具体**的实物、场所、仪式或平面传统——包括他们每天读的出版物、标识体系、数据图形、界面传统，不只是物理物件。**抽象但可命名的系统也算具体**（某个海报流派、某套文档标准）。

每个候选写两句：

- **为什么共鸣**，以及它如何承载步骤 1 的那个机制；
- **看起来什么样**：底色与主色、字体声部（几个声音、各干什么）、**一个让人一眼认出它的签名特征**。

按共鸣度排序。**近似候选只算一个。**

### 约束：必须跨 3 个材质族

如果 7 个候选里有**超过 3 个**共享同一个材质族（都是印刷品 / 都是金属器械 / 都是纺织品……），说明推导停在了主体最显眼的物件上——**继续往下挖，直到列表跨至少 3 个材质族**。

### 两个强制问题

- 这个东西**做成实物**会长什么样？
- 这个世界**在有网页之前**长什么样？

答不上来，说明候选还太抽象。

## 模式约束（决定「借多少」）

### operate（后台 / 看板 / 设置 / 工具）

**世界只借四件事，且只有这四件：type、palette、density、一个签名动作。它绝不提供布局、导航模型或控件。**

- 首视口按**产品外壳**写：导航在哪、工作区怎么分、访客先读哪些数据与状态，然后才说签名动作在哪。
- **签名动作必须具体到能在页面上找到**：服务健康画成线路图、排期按时刻表的列节奏排。**一个方向如果只以配色呈现，说明它还没找到那个动作。**
- 若世界取自受众操作的**工具或仪器**（终端、示波器、控制面板、驾驶舱），它只会变成那件工具的**戏服**：只取能转译为 type/palette/density/一个动作的部分，否则换一个候选。
- 配色要做实事：外壳的主色、状态色、数据系列、选中态、签名动作——**一个灰色界面加一个强调色不是克制，是没做**。

自检：盖住名字，它读起来像这个类别的**产品**吗？访客能从这里完成任务吗？它至少和类别里最好的产品一样干净、又比它更有辨识度吗？

### read（文档 / 指南 / 长文）

**世界拥有「框」，服务于「栏」。**

- **框** = 报头、导航轨、地（底色）、标题与章节开头、代码/表格/提示块的排法。世界在这里**完全投入**。
- **栏** = 阅读栏：阅读字体、真实对比、约 **60–75 字符**行宽、正文约 **16px**、文字背后没有任何表演。世界**不进入**阅读栏，也不替换阅读顺序或导航。
- 优先从世界自己的**出版传统**取（参考书、字体样本册、时刻表、野外手册、技术手册、学术排版、报纸的导航方式）。
- 首视口写：导航与读者所在位置、标题与回答问题的开篇、阅读栏、往前走的路径（目录、章节标题、上一篇/下一篇），再说世界在哪拥有框、签名动作在哪。

自检：读者能知道自己在哪、下一步去哪、并舒适地读完正文吗？盖上名字，这能不能是**任何其他产品**的文档？如果是，说明框还没被世界接管。

### experience（作品集 / 画廊 / 展陈）

- **作品从第一屏领跑，界面后退。**
- 首屏只放一件作品与一条展签；展签承担事实（编号、材质、年份），动机留给观众。
- 留白按展陈节奏分配，而不是均匀间距；界面装饰不得比作品更抢眼。

自检：第一眼看的是作品还是界面？如果把作品换成别的内容，这个页面还成立吗（说明界面在抢戏）？

## 骨架测试（每个首屏交付前必做）

**把文案全部抽掉，只看结构。** 层次与系统装置本身还能说出「这一段是什么、为什么重要」吗？

- 如果**只有文字回来才成立**，那所谓的"大胆"只在字号里，不在设计里。
- 占位图/占位块必须写明它承担什么任务（一个锚点、一件证据），而不是"放张装饰图"的提示。

## 反收敛自检清单

1. 7 个候选里，有几个来自「这个类别永远会发的那张页面」或它的反面？**必须为 0**。
2. 跨了几个材质族？**至少 3 个**。
3. 每个候选都能回答两个强制问题吗？
4. operate 方向：签名动作能指出来吗？还是只有配色？
5. read 方向：世界进到阅读栏里了吗？
6. 抽掉文案，骨架还站得住吗？
