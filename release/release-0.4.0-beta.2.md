# 天枢画布设计 v0.4.0-beta.2

> 2026-11-05 · Apache-2.0 · 预发布

修复 v0.4.0-beta 实测暴露的流程问题：模型会跳过「先给画布链接」与「先询问风格」两步。

---

## 修复

- **强制「先给画布链接 → 再问风格 → 最后写页面」的顺序**：实测中模型既没先把画布 URL 发给用户，也没询问风格就自行选定 Google 风开始生成页面。
  - 执行顺序改为编号硬约束（① 给链接 → ② 确认风格 → ③ 写页面 → ④ 自查）。
  - 新增「禁止」清单：明确禁止在用户选定风格前调用 `canvas_style` 的 `set` / `get` / `template`，并写明「**即使你觉得某套更合适，也必须先问**」；要求抛出选项后停下来等回答，不得同时往下写页面。
  - 「工作流」一节收敛为第 3 步的写法细节，去掉与硬约束重复的宽松表述。
  - `canvas_open` 返回文本改为「请立刻把下面这一行原样发给用户」，并提示下一步先确认风格。

## 说明

- 仅涉及技能文本与 `canvas_open` 的提示文案，**无工具接口 / 数据格式变更**。
- 设计系统（四套风格、注入、校验、画布切换）与 v0.4.0-beta 完全一致。
- 技能文本是模型行为的主要依据而非硬性拦截；若后续仍偶发跳步，可考虑在 `canvas_upsert_page` 增加运行时提示作为兜底。

---

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.4.0-beta.2`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
