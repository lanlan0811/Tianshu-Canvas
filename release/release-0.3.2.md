# 天枢画布设计 v0.3.2

> 2026-11-05 · Apache-2.0

新增**画布待机态**：空画布不再只是一张小插图，而是一块「准备好等你放东西的白板」。

---

## 新增

- **画布待机态**：等原型出现前的空态改为「顶部手绘动画 + 标题 + 说明 + 4 行快捷键说明」。
  - **顶部视觉**：手绘虚线画板（走 `#sketch` 抖动滤镜）+ 3 张便签小方片（琥珀/薄荷/天蓝）轻微浮动。
  - **标题 / 说明**：沿用「画布还是空白的」与「让天枢生成一个前端原型页面，再调用 canvas_upsert_page 贴到这块白板上。」
  - **4 行快捷键**：空格/中键拖拽·平移 · Ctrl+滚轮·缩放 · 滚轮·平移 · 点击·选中元素（Ctrl 点击选最内层）——逐字沿用原左下角提示条文案，配手绘键帽与纯 CSS 鼠标图标。

## 变更

- **空态时隐藏左下角提示条**：`.hint` 与待机态里的 4 行快捷键内容重复，空态下只显示待机态；有页面节点后 `.hint` 自动恢复。

## 说明

- 顶部视觉为**纯内联 SVG + CSS**，无外部资源、无 video（画布 CSP 未放宽，也不使用 emoji 图标）。
- 动画仅用 `transform`/`opacity`；系统开启「减少动态效果」（`prefers-reduced-motion`）时停止浮动。
- 导出模式（`?export=1`）隐藏待机态。
- 无破坏性工具/接口变更；工具仍为 5 个。

---

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.3.2`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
