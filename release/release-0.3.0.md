# 天枢画布设计 v0.3.0

> 2026-11-05 · Apache-2.0

画布界面**全面推翻重做**：从通用节点画布改为**手绘白板 / 便签风**，并重排交互外壳。

---

## 原因

原界面是通用的「浅灰底 + 网格 + 白色节点卡 + 蓝色选中」节点画布观感，容易被误认为短剧/电商类工具。本次整体换掉视觉与外壳结构，让它一眼就是「设计白板」。

## 视觉

- **配色**：奶油纸底 `#faf7f0` + 墨色 `#2b2b2b`，便签色（琥珀/薄荷/天蓝/珊瑚/丁香）点缀，暖色强调 `#e07a3f` 取代原蓝色。
- **背景**：直线网格 → **点阵纸**。
- **节点**：纸质卡片 + 手绘非对称圆角；标题栏带**胶带**装饰（按设备着色：desktop 琥珀 / tablet 天蓝 / mobile 薄荷 / free 丁香）。
- **字体**：标题/标签用系统手写体（楷体族）栈，正文用系统无衬线——**纯系统字体，无外链**（画布 CSP 不允许外链字体）。
- **连线**：墨色手绘线（双 path 抖动笔触 + 墨色箭头），标签为便签小片。
- **其他**：选中面板、节点工具栏、按钮、下拉菜单、空态、缩略图全部重绘为便签风。

## 结构

- 新增**顶栏**：品牌标、页面列表开关、适应视图、实时缩放百分比、导出下拉。
- 新增**左侧页面列表**：列出所有页面，点击选中并定位到该节点。
- 新增**右下角缩放控件**：缩小 / 百分比 / 放大 / 适应视图。
- 新增**右键菜单**：节点（重命名/复制/删除/置于顶层）、空白（适应视图）。
- 保留空格/中键平移、Ctrl+滚轮缩放、普通滚轮平移、12px 吸附等交互语义不变。

## 修复

- PNG 导出此前只按节点本体裁剪，**悬于节点上方的标题栏被切掉**；现在把标题栏一并纳入裁剪范围，导出包含标题与胶带。

## 影响

- 无破坏性工具/接口变更；工具仍为 5 个。
- 「置于顶层」为客户端行为，不写入项目数据，页面刷新/实时刷新后复位。
- 导出模式（`?export=1`）会隐藏全部新增外壳。

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.3.0`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
