# 天枢画布设计 v0.1.2

> 2026-11-04 · Apache-2.0

从「AI 写入画布」升级为**可迭代的设计工作台**：在画布上选中元素反馈给 AI、直接改文案与样式、
编排多页原型流程，并把成果导出交付。

---

## 亮点

### 1. 选中元素 → 加入对话

- 在画布上点击页面，可**两层选择**：普通点击选中当前区块，**Ctrl/Command 点击**选中最内层元素。
- 悬停高亮、选中徽标；选中项经本地服务落盘，AI 用 `canvas_get_selection` 读取后据此修改。
- 选中面板提供「**复制修改请求**」：一键生成含页面/元素/xpath/文案/关键样式的请求文本，粘贴给 AI。

### 2. 可视化编辑（文案 + 样式）

- 选中元素后，在面板中直接改**文案**与**样式**（文字颜色、背景色、字号、内边距、圆角等），
  「应用修改」即时生效并**回写原型 HTML**（写回文件已剥离探针与高亮痕迹）。

### 3. 画布编排

- 选中节点浮现工具栏：**重命名 / 复制 / 删除**；拖拽移动自动保存。
- 节点间可**连线**表示页面流程。
- 对应 AI 工具：`canvas_remove_page`、`canvas_rename_page`、`canvas_duplicate_page`、
  `canvas_move_page`、`canvas_link_pages`。

### 4. 导出交付

- **画布截图 PNG**：把整块画布（全部页面节点）渲染为一张 PNG，适合汇报/存档。
- **原型打包 ZIP**：打包所有页面 HTML + `project.json` + 自动生成的 `index.html` 画廊。
- 对应 AI 工具：`canvas_export`（`kind`: `png` / `zip` / `both`）。

## 安装 / 升级

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：

- **Git URL**：填本仓库地址（可指定标签 `v0.1.2`）。
- **本地路径**：填本仓库根目录的绝对路径。

> 已安装旧版的需**先卸载再安装**，并**新建会话**生效。

**PNG 导出**需要系统安装 Chrome 或 Edge；找不到时可用环境变量 `TIANSHU_CANVAS_BROWSER`
指定浏览器可执行文件路径（ZIP 导出不依赖浏览器）。

## 工具一览（10 个）

| 工具 | 用途 |
|---|---|
| `canvas_open` | 启动/复用本地画布服务，返回浏览器 URL |
| `canvas_add_page` | 把 HTML 原型作为页面节点加入画布 |
| `canvas_list_pages` | 列出画布上的页面节点 |
| `canvas_get_selection` | 读取画布上的当前选中项 |
| `canvas_remove_page` | 删除页面节点 |
| `canvas_rename_page` | 重命名页面节点 |
| `canvas_duplicate_page` | 复制页面节点 |
| `canvas_move_page` | 移动页面节点 |
| `canvas_link_pages` | 页面间连线/取消连线 |
| `canvas_export` | 导出画布 PNG 与/或原型 ZIP |

## 已知限制

- 画布仍在**浏览器中打开**（天枢插件无内嵌窗口能力）。
- 可视化编辑为**文案 + 样式**；不支持在页面内拖拽/缩放元素位置。
- 编辑回写为**整文档序列化**，可能轻微改变原 HTML 的格式（不改变语义）；原子写保证不会写坏。
- 原型运行在无同源权限的沙箱 iframe 中（有意的安全隔离）。

---

## 安全

- 服务仅绑定 `127.0.0.1`，校验 `Host` 头；静态资源白名单。
- 原型页与探针响应带严格 CSP；变更类路由要求自定义头 `X-Tianshu-Canvas`（防 CSRF）。
- 探针样式编辑走**白名单 + 值校验**（拒绝 `url(`/`expression`/`javascript:`/`@import`）。
- 导出文件仅按文件名访问（拒绝路径分隔符与 `..`）。
