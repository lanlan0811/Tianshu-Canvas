# 天枢画布设计 v0.3.1

> 2026-11-05 · Apache-2.0

合并两个社区修复 PR（[#2](https://github.com/lanlan0811/Tianshu-Canvas/pull/2)、[#3](https://github.com/lanlan0811/Tianshu-Canvas/pull/3)），修掉本地服务崩溃、项目文件被静默覆盖、画布编辑丢内容、节点高度失控、页面不刷新等问题。两个 PR 的改动已并入 v0.3.0 的便签风界面之上，冲突已解决。

---

## 本地服务与项目文件（PR #2）

- **进程不再被打垮**：`/page/:id` 畸形百分号编码返回 400；`GET //` 返回 400；JSON `null` 等非对象请求体返回 400；`handleRequest` 加顶层 `try/catch` 兜底，服务端故障返回 500（不泄露路径，详情只写日志），进程继续服务后续请求。
- **请求体超限**：先返回 413 再断开，修掉 Windows 上立刻断连发 RST 导致客户端读不到 413 的问题。
- **`project.json` 不再被静默覆盖**：读取时**不改动磁盘**（文件可能正处于 git 冲突或非原子保存的中间态，修好后画布自动恢复）；覆盖有问题的文件前先复制为 `project.json.corrupt-<时间戳>`，原始字节保留；单个节点或连线无效时同样提示并备份。
- **提示可见**：`canvas_get_state`、`/api/project` 与画布界面都会给出项目文件问题提示，写入结果带备份路径。
- **连线与选中校验**：`addEdge` 校验端点合法且节点存在、拒绝自环；`/api/selection` 校验 `pageId`；`removeEdge` 不校验端点，旧版本遗留的悬空连线/自环仍可删除。

## 画布编辑与渲染（PR #3）

- **改文案丢内容**：原来普通点击默认选中外层区块，文本框是截断到 200 字的纯文本，改一个字就会覆盖所有子元素并写回文件。现在只有不含子元素的元素才能改文案，输入框显示完整原文；区块会提示改用 Ctrl 点击具体文字。
- **回写源 HTML**：不再序列化 iframe 的运行时 DOM（脚本生成的内容下次加载会重复、弹窗等临时状态会被固化），改由 `web/src/sourceEdit.ts` 用 `DOMParser` 修改源 HTML，**确认保存成功后才更新画布预览**；xpath 找不到元素或文本对不上时拒绝回写并提示交给 AI；文件不再由 `__vd_edit_applied` 消息写入，页面脚本无法伪造它改写原型。
- **节点高度失控**：探针原先监听 `resize` 上报高度、节点又按上报值调整 iframe，形成反馈循环（`min-height:100vh` 的页面持续变高，`height:100vh` 的页面持续缩小）。现在只在页面加载完成时测量一次，节点不低于设计高度，测得高度在项目刷新后保留。
- **页面更新后不刷新**：节点新增 `htmlRev`，写入新 HTML 时更新，iframe 随之重新加载；只改标题或位置不会刷新；`/page/:id` 加 `Cache-Control: no-store`。
- **CSP 与文档矛盾**：文档改为要求原型自包含；`canvas_upsert_page` 检测到外链或相对路径时列出来提醒（CSP 未放宽）。

## 已知限制

- 脚本生成的元素不能直接回写文案。
- 含内联标签的文字（如 `<p>你好 <b>世界</b></p>`）只能改不含子元素的部分。
- 页面加载后才展开的内容不会让节点变高。

## 影响

- 无破坏性工具/接口变更；工具仍为 5 个。
- 两个 PR 的测试已并入：`test/regressions.test.mjs`（9 项）、`test/editing.e2e.test.mjs`、`test/resources.test.mjs`。
