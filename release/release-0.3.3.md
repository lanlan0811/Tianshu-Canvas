# 天枢画布设计 v0.3.3

> 2026-11-05 · Apache-2.0

放大画布待机态，让顶部浮动动画更明显。

---

## 变更

- **待机态整体放大**：
  - 插画区 `168×116 → 260×180`，画板 SVG `120×84 → 180×126`。
  - 便签小方片 `22px → 34px`，浮动幅度 `3px → 6px`（动画更明显）。
  - 标题 `20px → 26px`；说明 `13px → 15px`、宽度上限 `420 → 460`。
  - 键帽 `26px → 32px`（字号 12→13），纯 CSS 鼠标图标 `11×14 → 13×17`；快捷键行间距与区宽同步放大。

## 说明

- 仅调整 `web/src/EmptyState.tsx` 与 `web/src/styles.css` 的尺寸，结构与文案不变。
- 无破坏性工具/接口变更；工具仍为 5 个。

---

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.3.3`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
