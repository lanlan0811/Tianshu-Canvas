# 天枢画布设计 v0.4.0

> 2026-11-06 · Apache-2.0

正式版。本版把画布从「自由发挥」升级为**项目级设计系统**：内置 7 套风格、写入自动注入、只读风格校验，并新增**用户自定义设计系统**（含浅色 + 深色两套）。

相对上一个正式版 v0.3.3，工具由 5 个增至 **8 个**。

---

## 新增

### 自定义设计系统

用户说「要做一套设计系统」时，AI 主动问清配置（配色、圆角、字号、字体、动效、阴影、控件尺寸、深色），生成一套**只属于当前工作区**的风格，之后按它开发页面。

- **`canvas_design_system`** 工具（`action`: create / list / get / remove）：
  创建时传入完整 token 与图标描边；存于 `.tianshu-canvas/library/<id>/{tokens.json, meta.json}`，默认立即锁定为当前项目风格。
- **只改 token**：组件（`ts-*` 共 23 个）与图标（77 个）复用共享资源，不支持扩展；变量名须与内置风格一致，值自由。
- **浅色 + 深色两套**：生成 `:root{}` 与 `.dark{}` 两块、**同名** `--ts-color-*` 变量，共享的组件样式无需改动；深色在页面根元素加 `class="dark"` 即切换。
- **写入前校验**：对比度（浅色与深色各校验一遍，正文 ≥ 4.5）、尺度递增、变量名覆盖共享组件 / 模板、id 合法性与重名；不通过返回逐条中文错误。
- 仅本工作区生效（随 `.tianshu-canvas/` 一起被 gitignore，不随仓库分发）。

### 设计风格增至 7 套

在原有 4 套（苹果风 / 谷歌风 / Claude 风 / 天枢原创）基础上新增：

| id | 名称 | 特点 |
|---|---|---|
| `barbie` | 芭比风 | 亮粉与腮红色阶、超大圆角、粉色投影，衬线标题带编辑感 |
| `nerv` | NERV 风 | **深色**：深灰底 + 近白文字，霓虹红主操作，等宽字体读数 |
| `minimalist` | 极简风 | 纯中性黑白灰单色，层级靠明度与细边框，12px 圆角与极轻分层投影 |

同时把「天枢原创」**重新设计**为「宣纸青绿（东方文人）」：原设计与 Claude 风撞色（同为暖纸底 + 赭石棕主色 + 衬线标题），现改用冷绿宣纸底 `#f0f2ea` + 青绿主色 `#0f766e`，与 Claude 风彻底区分。

### 画布顶栏风格切换器

显示当前风格与色卡，可切换内置风格、自定义风格或回到「自由发挥」；AI 侧新建自定义风格后会自动出现在切换器里。

## 修复

合并社区 PR [#4](https://github.com/lanlan0811/Tianshu-Canvas/pull/4) 与 [#5](https://github.com/lanlan0811/Tianshu-Canvas/pull/5)（作者 jianbofei）。

- **设计系统注入**：切换风格后图标描边不生效（属性堆叠）；图标展开会破坏 `<script>` 里的字符串；无 `<html>`/`<head>` 的片段页面把样式块与探针插到 doctype 之前（怪异模式）。注入现在可逆、幂等，并跳过脚本 / 样式 / 注释。
- **画布状态**：`spawn` 失败走异步 `error` 事件会打垮宿主（`canvas_open`、PNG 导出、`taskkill`）；保存视口广播导致平移后丢失选中，且视口从未被读回。现在失败返回可读错误、不重试；保存视口不再广播，刷新保留选中与尺寸测量等客户端状态并恢复上次视口。
- **风格校验**：漏检多值简写 / 命名色 / 现代色函数 / 逻辑属性；误报 id 选择器 / 注释 / `data-style` / 负值 / emoji 掩码错位；未知 `style_id` 显示「通过」。`style_id=free` 如实说明只查资源。
- **尺度校验**：`space` 原只校验键名，而 JS 会按整数键自动排序，导致重复档位漏检；现同时校验值必须严格递增。
- **技能流程**：强制「先给画布链接 → 再问风格 → 最后写页面」的顺序，明确禁止在用户选定风格前调用 `set` / `get` / `template`。
- **测试基建**：浏览器 e2e 并发会互相争抢资源导致 `page.goto` 超时，改为串行执行。

## 变更

- **工具数 5 → 8**：新增 `canvas_style`、`canvas_check_style`、`canvas_design_system`。
- **`project.json` 新增可选字段** `design: { styleId, updatedAt }`；缺省即自由发挥，旧项目无需迁移。
- **`canvas_style` / `canvas_check_style` 的 `style_id` 不再是固定枚举**（改为自由字符串 + 执行期校验），这样工作区自定义风格 id 才能被接受。
- 发布工作流把含连字符的标签标记为预发布。

## 说明

- **未锁定风格时行为完全不变**：不注入、不改写页面 HTML。
- 切换风格只替换可用的 token 与组件实现，不会改写页面里已有的裸色值。
- 自定义风格的 token 与本项目的 `--ts-*` 变量体系完全兼容，可与内置风格随时互相切换。
- 内置风格产物在本次发布中**无变化**（7 套风格中仅「天枢原创」的配色在 beta.4 之后重设计过）。
- 风格为独立整理的视觉方案，与各品牌无隶属关系；详见 `design-systems/NOTICE.md`。
- 测试由 35 个增至 62 个，覆盖设计系统目录契约、注入与幂等、风格校验准确性、自定义设计系统（创建 / 注入浅深色 / 校验拒绝 / 跨工作区隔离 / 删除解绑）、画布状态与编辑 e2e（真实浏览器）。

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.4.0`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
