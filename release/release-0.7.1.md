# 天枢画布设计 v0.7.1

> 2026-11-06 · Apache-2.0

三套**原创设计风格**：天枢·砚、天枢·雾、天枢·麦。内置风格由 7 套增至 10 套。

三套风格均为从零设计：配色、字体、尺度、圆角与阴影独立定义，不是从现有风格提取或改色；
与既有风格共享组件契约、图标几何与模板结构（这是跨风格一致性的硬要求），差异全部来自 token。

---

## 新增风格

| id | 名称 | 一句话 | 适用 |
|---|---|---|---|
| `tianshu-inkstone` | 天枢·砚 | 石墨纸、朱砂印；小圆角、衬线标题、极轻投影 | 文档、审阅、内容型后台 |
| `tianshu-vapor` | 天枢·雾 | 雾蓝底、靛紫操作；大圆角、柔和投影、空气感层级 | 协作工具、AI 助手界面、现代后台 |
| `tianshu-saffron` | 天枢·麦 | 麦纸底、藏红花强调；中等圆角、手工印刷温度 | 内容社区、阅读产品、活动页 |

### 天枢·砚（`tianshu-inkstone`）

- 色板：冷灰纸面 `#f4f1ea` / 石墨 `#211d17` / 朱砂 `#a63a22`，中性色为石墨纸的完整 8 档。
- 字体：正文 Inter + 思源黑，标题思源宋/宋体，数据等宽。
- 尺度：2px 步进的紧凑间距、2–12px 小圆角、极轻分层阴影；字号 11–44px。
- **含深色模式**：墨底 `#17140f`，朱砂提亮为 `#b8442b`，正文对比 16.3:1。
- 对比度：正文/纸面 14.86:1，正文/卡片 16.76:1，主按钮白字 6.46:1；深色主按钮 5.38:1。

### 天枢·雾（`tianshu-vapor`）

- 色板：雾蓝灰 `#eef1f4` / 墨蓝 `#1b2430` / 靛紫 `#4453a8`。
- 字体：Inter + 思源黑，标题为同族大字号负字距，数据 IBM Plex Mono。
- 尺度：3px 步进的宽松间距、8–26px 大圆角、柔和多层投影；字号 11–50px。
- **含深色模式**：夜蓝 `#0f141b`，主操作反转为浅靛 `#7484d8` + 深色文字。
- 对比度：正文/底 13.81:1，主按钮白字 6.89:1；深色正文 15.82:1。

### 天枢·麦（`tianshu-saffron`）

- 色板：麦纸 `#fbf5e9` / 暖褐 `#33281a` / 藏红花 `#a35f08`。
- 字体：Inter + 思源黑，标题思源宋，数据 IBM Plex Mono。
- 尺度：4px 步进的舒适间距、4–16px 中等圆角；字号 11–52px，行高更舒展。
- 对比度：正文/底 13.25:1，主按钮白字 5.00:1（为此主按钮取加深一档的 `#a35f08`）。

## 变更

- `design-systems/index.json` 新增 3 条风格登记；`dist/design/` 重新构建（10 套产物）。
- README / `design-systems/README.md` 的风格数量与清单同步为 10 套。
- 测试：风格目录契约、服务端 catalog、图标注入测试同步到 10 套。
- 版本号 0.7.0 → 0.7.1（`package.json`、`tianshu.plugin.json`）。

## 兼容性

- 无接口与数据变更；旧项目直接可用，切换新风格时按现有机制重写页面并注入样式。
- 三套新风格不改变 `--ts-*` 变量名集合、组件类与模板 id，跨风格切换仍保持同构。
