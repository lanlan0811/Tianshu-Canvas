# 天枢画布设计 v0.1.1

> 2026-11-04 · Apache-2.0

修复工作流顺序问题：**先启动画布、把链接交给用户，再开始前端原型设计**。

---

## 修复

- **强制「先启动画布」的顺序**：技能说明把 `canvas_open` 明确为第一步 ——
  在用户拿到画布链接之前，不应开始生成原型或写入画布。
- **`canvas_add_page` 兜底**：即使未先调用 `canvas_open`，它也会自动确保画布服务在运行，
  并在返回里带上可点击的**画布 URL**，保证用户总能看到链接。
- **工具描述补充顺序提示**：`canvas_open` 标注为「画布设计的第一步」，
  `canvas_add_page` 说明返回会带画布 URL。

## 行为变化

- 调用 `canvas_add_page` 的返回现在**一定包含** `画布 URL：http://127.0.0.1:<port>/?ws=<token>`。
- 新增回归断言：未先 `canvas_open` 时，`canvas_add_page` 也必须返回画布 URL。

## 升级

插件安装为拷贝式，仓库改动不会自动同步。升级步骤：

1. 卸载旧版（插件中心移除，或 `/plugin remove tianshu-canvas`）。
2. 重新安装：Git URL 填本仓库地址（可指定标签 `v0.1.1`），或本地路径指向仓库根目录。
3. **新建会话**（安装/启用后需新会话才生效）。
