# 天枢画布设计 v0.9.2

> 2026-11-11 · Apache-2.0

修复 [Issue #7](https://github.com/lanlan0811/Tianshu-Canvas/issues/7)：编辑态点击嵌套链接不再出现 `unknown workspace`；手机、平板和自定义预览默认以 100% 原尺寸显示。

## 修复内容

- **原型点击**：链接从实际点击目标识别，不再误用逐层选中的外层区块。取消会离开原型的默认导航，保留既有站内跳转；Ctrl/Meta 点击只选中最内层。普通按钮、details、checkbox 和页内锚点继续正常工作。
- **预览清晰度**：默认进入与跨设备切换使用 100%，关闭重开恢复 100%；同设备点击和页面切换保留用户缩放。100% 不设置 transform，保留手动适配及 50%–200% 选项，不伪造 DPR。
- **溢出可达**：小内容居中，大内容从左上滚动可达；非网页预览增加底部留白，避免固定缩放按钮遮挡内容。10000×10000 等合法自定义尺寸可完整适配。
- **兼容与安全**：9 个工具、HTTP API、项目文件格式和权限保持不变。预览不改写原型或项目尺寸，服务端工作区鉴权、CSP 和 iframe sandbox 保持原有约束。

## 发布流程

本版本通过 `.github/workflows/release.yml` 发布。tag 必须属于 main 的历史，且相同提交的 main push CI 已成功；发布流程重新执行类型、构建、产物及许可一致性、严格浏览器测试、代码生成和插件自检。发布说明严格来自 `release/release-0.9.2.md`，缺失不回退。

## 升级与限制

- 从 0.9.1 升级，无项目数据迁移；更新插件后新建会话并重新打开画布。
- 声明平台仍为 Windows x64，天枢 `>=4.0.2 <5.0.0`；未扩大平台支持范围。
- 本轮自动化使用真实浏览器和最小测试宿主；天枢 GUI 手工安装/交互与 Windows 经典原生滚动条配置未完成专项实测，不将旧版手工验收冒充本版结果。
- 手动缩小预览受物理像素限制，不承诺与 100% 完全相同的文字像素表现。
