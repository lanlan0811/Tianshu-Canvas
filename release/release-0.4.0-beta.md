# 天枢画布设计 v0.4.0-beta

> 2026-11-05 · Apache-2.0 · 预发布

引入**项目级设计系统**：四套视觉风格、写入时自动注入、画布可切换、只读风格校验。

---

## 新增

### 设计系统（4 套风格）

内置四套风格，均使用统一的 `--ts-*` 变量与 `ts-*` 组件类：

| id | 名称 | 特点 |
|---|---|---|
| `apple` | 苹果风 | 克制、留白、系统蓝 |
| `google` | 谷歌风 | 明亮、秩序、4dp 网格 |
| `claude` | Claude 风 | 暖纸、赭石强调、编辑感 |
| `tianshu-original` | 天枢原创 | 墨纸与琥珀色的手作感界面 |

每套含：颜色 / 字体 / 间距 / 圆角 / 阴影 / 尺寸 token、23 个组件类、60–80 个内联 SVG 图标、2 个页面模板（数据看板 / 落地页）。

> 风格为独立整理的视觉方案（style aliases），与 Apple、Google、Anthropic 等公司**无隶属或背书关系**；相关商标归各自所有者。颜色值、组件样式与模板均为本项目自行编写，字体一律使用系统字体栈。

### 新工具

| 工具 | 用途 |
|---|---|
| `canvas_style` | 列出 / 查看 / 锁定 / 切换项目级风格；取页面模板 HTML（`action`: list / get / set / template） |
| `canvas_check_style` | 只读检查页面是否符合当前风格：裸色值、非 token 字体、越界间距 / 圆角、目录外图标与组件类、未知变量、会被 CSP 拦截的资源 |

### 画布

- **顶栏风格切换器**：显示当前风格名与色卡，点开可切换或回到「自由发挥」，底部附无隶属声明。
- 切换后服务端重写所有页面并广播，iframe 自动刷新。

### 自动注入

锁定风格后，`canvas_upsert_page` 写入时自动把 token 与组件样式内联进 `<head>`，并把 `<svg data-icon="名字">` 展开为当前风格的内联 SVG。原型保持自包含，严格 CSP 下无需任何外链。

## 变更

- `project.json` 新增可选字段 `design: { styleId, updatedAt }`；缺省即「自由发挥」，旧项目无需迁移。
- 工具数由 5 个增至 7 个。
- `canvas_get_state` 新增「设计风格」段。
- 发布工作流：含连字符的标签（如本版本）会标记为**预发布**，不占据 latest。

## 说明

- **未锁定风格时行为完全不变**：不注入、不改写 HTML，页面字节与旧版一致。
- 切换风格只替换可用的 token 与组件实现，**不会**把页面里已有的裸色值改写成 `var()`；这类页面请用 `canvas_check_style` 定位后按需修改。
- 解绑（回到自由发挥）不剥离已有样式块，避免页面突然失去样式。
- v1 只有项目级风格，不支持单页单独设风格；暗色主题仅预留结构，未实现。

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.4.0-beta`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
