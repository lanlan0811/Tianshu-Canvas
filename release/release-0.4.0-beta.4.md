# 天枢画布设计 v0.4.0-beta.4

> 2026-11-06 · Apache-2.0 · 预发布

设计风格由 4 套增至 **7 套**：新增芭比风、NERV 风、极简风。

---

## 新增 · 设计风格

三套新风格沿用统一的 `--ts-*` 变量与 `ts-*` 组件类，图标 / 组件 / 模板仍为全部风格共享，因此它们与既有风格**类名与 DOM 结构完全同构**，切换时只替换样式块。

| id | 名称 | 特点 |
|---|---|---|
| `barbie` | 芭比风 | 亮粉与腮红色阶、超大圆角、粉色投影，衬线标题带编辑感 |
| `nerv` | NERV 风 | **深色**：深灰底 + 近白文字，霓虹红主操作，等宽字体读数 |
| `minimalist` | 极简风 | 纯中性黑白灰单色，层级靠明度与细边框，12px 圆角与极轻分层投影 |

- **NERV 风是本项目首套深色风格**（底 `#0f0f10`、文字 `#ffffff`）。
- 变量集合与既有风格完全一致（每套 116 个），构建期跨风格一致性校验通过。

### 主色取值

构建期要求主按钮文字对主色对比度 ≥ 4.5，源参考色直接沿用会不达标，因此**主色按同色系调深**，品牌亮色保留在图表色阶与强调位：

| 风格 | 主色 | 白字对比度 |
|---|---|---|
| 芭比风 | `#d81b60`（参考 `#e91e63`） | 4.95 |
| NERV 风 | `#cc363b`（参考 `#ea343a`） | 5.05 |
| 极简风 | `#18181b` | 17.72 |

## 变更

- `design-systems/index.json` 登记三套新风格；`NOTICE.md` 补充与 Mattel（Barbie）及《新世纪福音战士》相关权利方无隶属关系的声明；`README.md` 表述由「四套」改为「全部风格」。
- 画布顶栏风格切换器与 `canvas_style`（action=list）现在列出 7 套风格。

## 说明

- **无工具接口 / 数据格式变更**，`project.json` 结构不变，旧项目无需迁移；已锁定风格的页面不受影响。
- 工具数量仍为 7 个。
- 测试由 52 个增至 52 个（新增风格并入既有跨风格同构用例，断言覆盖 7 套产物）。

## 升级后你需要做的
