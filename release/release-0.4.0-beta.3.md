# 天枢画布设计 v0.4.0-beta.3

> 2026-11-06 · Apache-2.0 · 预发布

合并社区 PR [#4](https://github.com/lanlan0811/Tianshu-Canvas/pull/4) 与 [#5](https://github.com/lanlan0811/Tianshu-Canvas/pull/5)（作者 jianbofei），修复设计系统注入、画布状态与风格校验的一批缺陷。

---

## 修复 · 设计系统注入（PR #4）

- **切换风格后图标描边不生效**：每次注入都会追加 `stroke-width` 等属性，HTML 解析器只认第一个，切到新风格后线宽不变；重复设置同一风格也会重写页面。现在注入前先移除由风格接管的描边属性，切换与重设都可逆、幂等。
- **图标展开破坏页面脚本**：`<script>` 里的 `<svg data-icon="…">` 字符串会被替换成展开后的 SVG，插入的引号可能截断 JS 字符串，让整段脚本失效。现在展开时跳过 `script`、`style` 与注释；脚本里未被展开的图标会在工具返回里提示改用 `<template>`。
- **样式块与探针插到 doctype 之前**：没有 `<html>` / `<head>` 标签的片段页面，注入内容会落在 `<!doctype>` 之前，使页面进入怪异模式。现在两者都插在 doctype 之后。

## 修复 · 画布状态与校验（PR #5）

- **浏览器无法启动会打垮宿主**：`spawn` 失败走异步 `error` 事件，`try/catch` 接不住，会变成未捕获异常。现在 `canvas_open` 打不开系统浏览器时只记日志并正常返回；PNG 导出在浏览器程序本身无法启动时返回可读错误且不再重试；`taskkill` 也补了错误监听。
- **平移后丢失选中**：保存视口会广播项目变更，画布随之全量重建节点，连续滚动约 500ms 后选中消失；保存的视口也从未被读回。现在保存视口不再广播，项目刷新保留选中、置顶与尺寸测量等客户端状态，打开时恢复上次视口，看不到任何节点时回退到适应视图，且只保存用户操作。
- **风格校验不准**：
  - 漏检：多值简写（`padding:13px 7px`）、命名色（`color:red`）、现代色函数（`oklch()` / `hwb()` / `color()`）、逻辑属性（`padding-inline`）。
  - 误报：id 选择器（`#face`）、CSS 注释、`data-style` 属性、尺度内的负值、emoji 造成的掩码错位。
  - 未知 `style_id` 现在返回错误而不是显示「通过」；`style_id=free` 如实说明只检查资源引用。

## 说明

- **无工具接口 / 数据格式变更**，`project.json` 结构不变，旧项目无需迁移。
- 工具数量仍为 7 个；`canvas_check_style` 的 `style_id` 参数新增 `free` 取值。
- 测试由 35 个增至 52 个，新增图标注入、画布状态（真实浏览器）、风格校验准确性、spawn 错误回归。

## 升级后你需要做的

通过天枢「插件中心 → 社区插件 → 从其他来源安装」：填本仓库地址（可指定标签 `v0.4.0-beta.3`），或填本仓库根目录的绝对路径。已安装旧版的需**先卸载再安装**，并**新建会话**生效。
